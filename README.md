# API-ong

# Estudantes: Gabriele Carolina de Lima Queiroz e Felipe de Mauro Paulo.

Tema: Doações e Voluntariado para ONG

Problema: Dificuldade em encontrar e fazer doações, junto a pouco controle sobre a quantidade arrecadada para a meta.

Requisitos Funcionais (O que o sistema faz)

• Painel de metas: Mostrar o progresso das arrecadações em tempo real.
• Doação flexível: Permitir doações identificadas ou anônimas.
• Gestão de voluntários: Cadastrar pessoas e escalá-las para as ações da ONG.

Requisitos Não Funcionais (Como o sistema deve ser)

• Seguro: Proteger dados financeiros e garantir o anonimato de quem pediu sigilo.
• Rápido: Atualizar a barra de metas instantaneamente e carregar páginas em até 2 segundos.
